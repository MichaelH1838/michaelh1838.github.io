Bit-Accurate DSP Hardware Models in Python

Cycle-accurate fixed-point models of delta-sigma DACs, NCOs and LFSR/GPS code generators, used to verify FPGA designs bit-for-bit.

Overview

A professional course on using Python as the modeling and verification side of digital hardware design. The core idea: write a model that matches the RTL bit-for-bit and clock-for-clock, then use it as the golden reference for the FPGA.

Every model was written as a Python generator that steps one clock at a time, doing sequential updates first and combinational logic second, with a debug mode that returns every internal node.

What I did

  • Modeled accumulators and a 2nd-order delta-sigma DAC in fixed point with saturation, then pushed the output through a Sallen-Key filter model to estimate ENOB.
  • Built the sine look-up table for a numerically controlled oscillator (phase accumulator → truncation → LUT).
  • Wrote an LFSR PRN generator over GF(2), then used it for DSSS spreading and to pull hidden data out of an audio file.
  • Generated GPS C/A Gold codes and correlated them against a real captured GPS signal to find satellite SV24.
  • Streamed FPGA simulation output line by line against the Python model to catch mismatches as they happen.
