Elevator Controller on a DE10-Lite FPGA

Digital-logic elevator controller designed from truth tables and K-maps, minimized to the fewest gates, and run on an Intel DE10-Lite.

Role
Lead circuit designer
Where
Digital Logic (ELEC 2275), Wentworth
When
Dec 2024

Overview

An elevator controller built the way real digital design starts: define the behavior, write it as truth tables and a state diagram, minimize it, implement it, and prove it works for every input combination.

What I did

  • Wrote the truth tables and state diagram, then simplified with Boolean algebra and Karnaugh maps to find the prime implicants.
  • Compared several circuit configurations and reduced each to its minimal form, checking every simplified expression against the original table.
  • Implemented the design in Intel Quartus and ran it on a DE10-Lite board.
  • Verified behavior with waveform simulation across all input combinations.
