Wall-Following Control for iRobot Create 3

Continuous-feedback wall-following controller in Python using the robot's IR proximity sensors, with corner handling and wall reacquisition.

Role
Lead Python developer
Where
Wentworth Institute of Technology
When
Dec 2025

Overview

An autonomous wall-following behavior for the iRobot Create 3. The goal was to hold a steady distance from a wall and adapt to obstacles and changes in the room, the way animals follow boundaries.

The controller grew from simple stop-and-go reactions into a continuous feedback loop, which turned out to be the key lesson: gradual, sensor-driven control beats rigid on/off rules in the real world.

What I did

  • Fused the front IR sensors (collision avoidance) with the right-side sensor (wall distance).
  • Used shallow arcs to settle onto walls, which cut wheel slip, sensor-latency effects and oscillation.
  • Added error-correction routines for 90° corners and for reacquiring a lost wall.
  • Used the robot's LEDs as a live readout of the navigation state.
